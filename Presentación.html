🔄 Flujo del Proceso

📝 Usuario sube CV
🔍 Extracción de texto
🤖 Análisis con IA
🎯 Generación de perfiles
🌐 Búsqueda de ofertas
📊 Cálculo de compatibilidad
📧 Envío de resultados
  • Extracción: Mistral OCR procesa múltiples formatos (PDF, Word, BMP, JPG, PNG)
  • Análisis: GPT-4 identifica fortalezas, mejoras y genera perfiles
  • Búsqueda: JSearch API encuentra ofertas en múltiples países
  • Scoring: Calcula compatibilidad por skills y experiencia
  • Reporte: Email HTML con análisis completo y ofertas
